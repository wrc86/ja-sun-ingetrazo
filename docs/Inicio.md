## Instalación rápida

1. Descarga `ja_sun-0.1.0.zip` y descomprímelo.
2. En IngeTrazo abre **Extensiones → Abrir carpeta de plugins**.
3. Copia la carpeta `ja_sun` completa y reinicia el programa.
4. Abre JA Sun desde **Extensiones**.

El ZIP es para IngeTrazo, no un RBZ para SketchUp. Al actualizar, sustituye la carpeta correspondiente y evita copias duplicadas.

## Ayuda

Si la extensión no aparece, comprueba que `ja_sun/__init__.py` esté directamente dentro de la carpeta del plugin, que los iconos se hayan copiado y que hayas reiniciado IngeTrazo. Para un reporte incluye versión del programa, versión de la extensión, sistema operativo, pasos y resultado esperado.
